# أونصة — قراءة ذهب الفوركس

مساعد لقراءة أونصة الذهب على الفوركس: شموع السعر، أنماطها، وميل الإطار الزمني، مع التقويم الاقتصادي والعناوين التي تحرّك الذهب.

الأداة لا تفتح صفقات ولا تعطي أمر شراء أو بيع. القراءة تعليمية، والتداول بالرافعة يمكن أن يخسّر رأس المال.

## التشغيل

```bash
cd gold-fx
npm install
npm run dev
```

يفتح على `http://localhost:3003`

```bash
npm test
npm run build
```

## ماذا ترى

- **سبوت XAU** وسعر **عقد COMEX (GC)** الذي تُرسم منه الشموع. العقد يتحرك مع الأونصة ولا يطابقها دائماً.
- إطارات 5 دقائق، 15 دقيقة، ساعة، 4 ساعات، ويوم.
- متوسط 21 الأسي ومتوسط 50، وRSI، وATR، وأقرب دعم ومقاومة.
- تشريح الشمعة عند تمرير المؤشر: الجسم، الذيول، والنمط إن وُجد.
- تقويم الأسبوع للأخبار المؤثرة على الدولار والذهب، مع شرح مبسّط: ماذا يعني رقم أقوى أو أضعف من المتوقع.
- عناوين حديثة عن الذهب مع تصنيف عربي للموضوع.

## البيانات

الشموع من Yahoo Finance لعقد `GC=F`، والسبوت من `api.gold-api.com`، والتقويم من ملف الأسبوع العام لـ Forex Factory، والعناوين من بحث Google News. قد تتأخر الأسعار عن وسيطك. عند النشر على Vercel اجعل مجلد المشروع `gold-fx` حتى تعمل مسارات `api/`.
