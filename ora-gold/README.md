# Ora Gold

تطبيق ويب لإدارة ميزانية معمل الذهب: المصاريف، الأجور، الأرباح، والمدفوعات.

## التشغيل المحلي

```bash
cd ora-gold
npm install
npm run dev
```

يفتح على `http://localhost:3002`

## النشر على Vercel

1. ارفع المشروع على GitHub
2. من [vercel.com](https://vercel.com) → **Add New Project**
3. اختر المستودع وحدد **Root Directory** = `ora-gold`
4. Framework: **Vite** — Build: `npm run build` — Output: `dist`
5. اضغط **Deploy**

أو من الطرفية داخل مجلد `ora-gold`:

```bash
npx vercel --prod
```

## الميزات

- **يفتح معبّى مسبقاً** — بيانات `ميزانية-05-2026.xlsx` (أكثر من 3800 حركة)
- **لوحة ملخص** — مثل ورقة «رئيسي» مع فحص التوازن
- **حسابات متعددة** — ماكينات، مصاريف، أرباح، مساهمين، أجور، زبائن
- **خزنة رئيسية** — جرد المخزون
- **استيراد / تصدير Excel**
- **استعادة Excel الأصلي**
- **نسخة احتياطية JSON**

## ملاحظات

- البيانات تُحفظ تلقائياً في `localStorage`
- للنسخ الاحتياطي: «نسخة احتياطية» أو «تصدير Excel»
