# Ora Gold

تطبيق ويب لإدارة ميزانية معمل الذهب: المصاريف، الأجور، الأرباح، والمدفوعات.

## التشغيل المحلي

```bash
cd ora-gold
npm install
cp .env.example .env.local   # اختياري — للمساعد الذكي
npm run dev
```

يفتح على `http://localhost:3002`

### مساعد الذكاء الاصطناعي (اختياري)

1. انسخ `cp .env.example .env.local`
2. عيّن `VITE_AI_API_KEY` (ومن ثم أعد `npm run dev`)
3. أو أدخل المفتاح من التطبيق: زر المساعد أسفل الشاشة → **إعدادات**

على **Vercel**: أضف `VITE_AI_API_BASE`, `VITE_AI_API_KEY`, `VITE_AI_MODEL` في Environment Variables.  
التفاصيل والمزودون البديلون: راجع التعليقات داخل `.env.example`.

## النشر على Vercel

1. ارفع المشروع على GitHub
2. من [vercel.com](https://vercel.com) → **Add New Project**
3. اختر المستودع وحدد **Root Directory** = `ora-gold`
4. Framework: **Vite** — Build: `npm run build` — Output: `dist`
5. اضغط **Deploy**

أو من الطرفية داخل مجلد `ora-gold`:

```bash
npx vercel --prod
```

## الميزات

- **يفتح معبّى مسبقاً** — بيانات `ميزانية-05-2026.xlsx` (أكثر من 3800 حركة)
- **لوحة ملخص** — مثل ورقة «رئيسي» مع فحص التوازن
- **حسابات متعددة** — ماكينات، مصاريف، أرباح، مساهمين، أجور، زبائن
- **خزنة رئيسية** — جرد المخزون
- **دورة عمل Excel** — مراحل الورشة، مسارات الفواتير (متاجرة / زبون ورشة)، وأعمدة مطابقة (Trading بيع/شراء، مشغول 18 تسليم زبائن…)
- **استيراد / تصدير Excel**
- **استعادة Excel الأصلي**
- **نسخة احتياطية JSON**
- **طباعة الفواتير** — كاملة، بأقسام، أو كل قسم في صفحة
- **أوامر صرف** — مشتريات ومصاريف ($)
- **مساعد ذكي** — محلي أو عبر API (انظر `.env.example`)

## ملاحظات

- البيانات تُحفظ تلقائياً في `localStorage`
- للنسخ الاحتياطي: «نسخة احتياطية» أو «تصدير Excel»
