# تحديث مستودع shasha-asear

هذه الحزمة نسخة جاهزة من تطوير **شاشة أسعار** (مزامنة MT5 للموبايل/التلفزيون).

## تطبيق على جهازك

```bash
git clone https://github.com/Georgebahna57/shasha-asear.git
cd shasha-asear
bash /path/to/export/shasha-asear-update/apply.sh
git push origin main
```

أو من مجلد `shasha-asear` بعد نسخ مجلد `export/shasha-asear-update` إليه:

```bash
bash shasha-asear-update/apply.sh
git push origin main
```

بعد النشر على GitHub Pages، اتبع `docs/RELAY-AR.md` لربط Supabase.
