# ميزانية الورشة — معمل الذهب

تطبيق ويب لتسهيل إدارة ميزانية معمل الذهب: المصاريف، الأجور، الأرباح، والمدفوعات.

## التشغيل

```bash
cd workshop-budget
npm install
npm run dev
```

يفتح على `http://localhost:3002`

## الميزات

- **لوحة ملخص** — مثل ورقة «رئيسي» في Excel مع فحص التوازن (ذهب + دولار)
- **حسابات متعددة** — ماكينات، مصاريف تشغيلية، أرباح، مساهمين (أحمد/مازن)، أجور، زبائن...
- **خزنة رئيسية** — جرد المخزون (دهب، فضة، دولار، مشغول...)
- **استيراد Excel** — من ملف الميزانية الحالي
- **تصدير Excel** — بنفس هيكل الأوراق
- **نسخة احتياطية JSON** — حفظ محلي في المتصفح

## الاستخدام

1. اضغط **استيراد Excel** واختر ملف `ميزانية-05-2026.xlsx`
2. راجع لوحة الملخص — يجب أن يكون «الفرق» صفراً
3. أضف حركات جديدة من أي حساب
4. صدّر Excel عند الحاجة

## ملاحظات

- البيانات تُحفظ تلقائياً في `localStorage` للمتصفح
- للنسخ الاحتياطي الدائم: استخدم «نسخة احتياطية» أو «تصدير Excel»
